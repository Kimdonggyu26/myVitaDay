# 화면 명세서

## 1. 목적

이 문서는 VitaDay MVP의 핵심 화면이 어떤 역할을 하고, 어떤 정보와 행동을 포함해야 하는지 정리한 기준 문서입니다.

이 문서의 목표는 다음 3가지입니다.

- 디자인 전에 화면 목적을 흔들리지 않게 고정한다.
- 프론트엔드와 백엔드가 같은 데이터 구조를 바라보게 한다.
- 나중에 기능 추가 요청이 들어와도 핵심 화면 복잡도를 통제한다.

## 2. MVP 핵심 화면 목록

- 온보딩 및 로그인
- 홈
- 검색
- 제품 상세
- 제품 비교
- 저장한 제품
- 내 영양제

분석, 루틴, 알림은 P1 이후 확장 화면으로 본다.

## 3. 공통 UI 원칙

- 첫 화면에서 사용자가 바로 검색할 수 있어야 한다.
- 상세 화면은 정보가 많아도 위에서 아래로 자연스럽게 읽히게 구성한다.
- 비교 화면은 표를 복잡하게 만들지 않고 핵심 비교 항목을 우선한다.
- 가격 정보에는 항상 갱신 시점을 표시한다.
- 외부 구매 링크는 앱 내 핵심 흐름을 해치지 않게 배치한다.

## 4. 화면별 명세

### 4.1 온보딩 및 로그인

#### 목적

- 서비스의 핵심 가치를 짧게 전달한다.
- 사용자가 로그인 또는 회원가입을 완료하게 한다.
- 이후 저장과 내 영양제 기능 사용을 위한 계정 진입점을 만든다.

#### 핵심 메시지

- 영양제를 쉽게 찾고 비교할 수 있다.
- 관심 제품과 내 영양제를 저장할 수 있다.

#### 주요 요소

- 서비스 소개 문구
- 회원가입 버튼
- 로그인 버튼
- 추후 소셜 로그인 자리 여백

#### 주요 행동

- 회원가입 진입
- 로그인 진입
- 로그인 완료 후 홈 이동

#### 상태

- 기본 상태
- 로그인 실패 상태
- 회원가입 검증 실패 상태

#### 연결 API

- `POST /auth/signup`
- `POST /auth/login`

### 4.2 홈

#### 목적

- 사용자가 다시 왔을 때 바로 검색하거나 저장한 제품으로 돌아가게 한다.
- 검색 중심 서비스라는 인상을 준다.

#### 주요 요소

- 상단 검색 입력창 또는 검색 진입 버튼
- 최근 본 제품 섹션
- 저장한 제품 섹션
- 많이 비교되는 제품 섹션
- 내 영양제 바로가기

#### 주요 행동

- 검색 화면 이동
- 최근 본 제품 상세 이동
- 저장한 제품 목록 이동
- 내 영양제 이동

#### 상태

- 신규 사용자 상태
- 최근 본 제품 없음 상태
- 저장한 제품 없음 상태

#### 비고

- 신규 사용자는 검색 유도 카드가 가장 먼저 보여야 한다.

### 4.3 검색

#### 목적

- 사용자가 원하는 영양제를 빠르게 찾게 한다.
- 비교 가능한 후보를 탐색하게 한다.

#### 주요 요소

- 검색 입력창
- 최근 검색어
- 추천 카테고리
- 검색 결과 리스트
- 필터 또는 정렬 영역의 자리

#### 검색 결과 카드 항목

- 제품명
- 브랜드명
- 카테고리
- 핵심 성분 요약 1줄
- 최저가 또는 대표 가격
- 저장 버튼
- 비교 담기 버튼

#### 주요 행동

- 제품명 검색
- 브랜드 검색
- 카테고리 탐색
- 제품 상세 이동
- 비교 담기
- 저장

#### 상태

- 초기 상태
- 검색 결과 존재 상태
- 검색 결과 없음 상태
- 로딩 상태
- 네트워크 에러 상태

#### UX 규칙

- 검색 결과 없음 상태에서는 비슷한 카테고리 진입을 제안한다.
- 비교 담기는 최대 3개까지만 허용한다.

#### 연결 API

- `GET /products/search?q=`
- `GET /categories`

### 4.4 제품 상세

#### 목적

- 사용자가 제품 하나를 충분히 이해하고 저장, 비교, 구매 중 하나를 선택하게 한다.

#### 주요 요소

- 제품 이미지
- 제품명
- 브랜드명
- 카테고리
- 제품 요약 문구
- 1일 섭취량
- 주요 성분 리스트
- 주의 문구
- 판매처별 가격 섹션
- 저장 버튼
- 비교 담기 버튼
- 내 영양제로 등록 버튼

#### 주요 성분 섹션 항목

- 성분명
- 함량
- 표시 단위

#### 가격 섹션 항목

- 판매처명
- 가격
- 구매 링크 버튼
- 마지막 갱신 시각

#### 주요 행동

- 저장
- 비교 담기
- 내 영양제로 등록
- 구매 링크 이동

#### 상태

- 정상 상태
- 가격 정보 없음 상태
- 성분 정보 일부 누락 상태
- 외부 링크 비활성 상태

#### UX 규칙

- 가격 정보가 없더라도 상세 자체는 열려야 한다.
- 의료 효능처럼 오해될 수 있는 문구는 사용하지 않는다.

#### 연결 API

- `GET /products/{id}`
- `GET /products/{id}/offers`
- `POST /saved-products`
- `POST /regimen-items`

### 4.5 제품 비교

#### 목적

- 사용자가 여러 제품의 차이를 한눈에 이해하게 한다.
- 비교 후 저장 또는 구매 판단으로 이어지게 한다.

#### 비교 기본 수량

- 기본 2개 비교
- 최대 3개 비교

#### 주요 요소

- 비교 대상 제품 헤더
- 제품별 이미지, 제품명, 브랜드명
- 가격 비교 행
- 1일 섭취량 비교 행
- 주요 성분 비교 표
- 특징 요약 비교 행
- 저장 버튼
- 상세 보기 버튼
- 구매 링크 버튼

#### 비교 우선 항목

- 가격
- 주요 성분
- 함량
- 섭취량
- 특징 요약

#### 주요 행동

- 제품 제거
- 다른 제품 추가
- 저장
- 상세 이동
- 구매 링크 이동

#### 상태

- 2개 비교 상태
- 3개 비교 상태
- 비교 대상 1개만 남은 상태
- 가격 정보 일부 누락 상태

#### UX 규칙

- 모든 성분을 다 노출하기보다 핵심 성분 우선 표시 후 전체 펼치기를 둔다.
- 차이점이 눈에 띄도록 같은 행 기준 정렬을 유지한다.

#### 연결 API

- `GET /products/compare?ids=1,2`

### 4.6 저장한 제품

#### 목적

- 사용자가 나중에 다시 볼 제품을 쌓아두고 재비교하게 한다.

#### 주요 요소

- 저장 목록
- 최근 저장일
- 가격 요약
- 비교 선택 체크
- 삭제 버튼
- 내 영양제로 등록 버튼

#### 주요 행동

- 상세 이동
- 비교 화면 이동
- 저장 해제
- 내 영양제로 등록

#### 상태

- 저장 목록 존재 상태
- 빈 상태

#### UX 규칙

- 빈 상태에서는 검색으로 돌아가도록 강하게 유도한다.

#### 연결 API

- `GET /saved-products`
- `DELETE /saved-products/{id}`
- `POST /regimen-items`

### 4.7 내 영양제

#### 목적

- 사용자가 현재 복용 중인 영양제를 정리하게 한다.
- 이후 분석과 루틴 기능으로 확장할 준비를 한다.

#### 주요 요소

- 등록 제품 목록
- 복용 횟수
- 메모
- 활성 여부
- 제품 상세 바로가기
- 분석 기능 예고 또는 진입 버튼

#### 주요 행동

- 등록 목록 조회
- 메모 수정
- 복용 횟수 수정
- 비활성 처리 또는 삭제
- 추후 분석 진입

#### 상태

- 등록 목록 존재 상태
- 빈 상태

#### UX 규칙

- 빈 상태에서는 저장 목록 또는 검색으로 이동할 수 있어야 한다.

#### 연결 API

- `GET /regimen-items`
- `PATCH /regimen-items/{id}`
- `DELETE /regimen-items/{id}`

## 5. P1 확장 화면 메모

### 분석 결과

- 중복 성분
- 기본 주의사항
- 부족 가능성 안내

### 루틴 및 알림

- 시간 슬롯
- 알림 시간 설정
- 복용 체크

P1 화면은 P0 핵심 흐름을 해치지 않는 선에서 뒤에 붙인다.

## 6. 화면 우선순위

### 가장 먼저 디자인할 화면

1. 검색
2. 제품 상세
3. 제품 비교
4. 저장한 제품

### 그다음 화면

1. 홈
2. 내 영양제
3. 온보딩 및 로그인

## 7. 구현 순서 연결

- 검색 화면 설계가 끝나면 검색 API 상세 명세로 넘어간다.
- 상세 화면 설계가 끝나면 제품, 성분, 가격 응답 구조를 확정한다.
- 비교 화면 설계가 끝나면 비교 응답 포맷을 고정한다.
- 저장한 제품과 내 영양제 화면 설계가 끝나면 인증 이후 사용자 데이터 모델을 고정한다.
