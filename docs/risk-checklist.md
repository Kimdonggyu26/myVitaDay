# 리스크 체크리스트

## 1. 의료 표현 리스크

- 서비스가 의료 진단 또는 치료 대안처럼 보이지 않는가
- 부족 가능성 표현에 확정적 문구를 쓰지 않는가
- 사용자 상태에 따라 전문가 상담 권장 문구가 필요한가

## 2. 데이터 리스크

- 제품 데이터 출처가 명확한가
- 직접 입력 제품을 허용할 때 분석 한계를 안내하는가
- 성분 단위와 함량 데이터가 일관적인가

## 3. 추천 리스크

- 왜 이 추천이 나왔는지 설명 가능한가
- 사용자 목표와 현재 복용 제품의 연결 근거가 있는가
- 추천 결과가 과도하게 상업적으로 보이지 않는가

## 4. 알림 리스크

- 너무 잦은 알림으로 피로를 주지 않는가
- 권한 거부 시 대체 진입점이 있는가
- 시간대 변경과 휴대폰 설정 변화에 대응하는가

## 5. 보안 리스크

- 비밀번호를 해시 저장하는가
- JWT와 리프레시 토큰 회전 정책이 있는가
- 개인정보와 건강 목표 데이터 접근 권한이 분리되는가

## 6. 운영 리스크

- 고객 문의가 들어왔을 때 어떤 범위까지 답변할지 정해졌는가
- 잘못된 추천 신고를 처리하는 운영 플로우가 있는가
- 구매 링크나 제휴 상품 변경 시 업데이트 절차가 있는가

## 7. 출시 전 점검 질문

- 이 앱 없이도 해결 가능한 문제를 충분히 더 편하게 만들었는가
- 첫날 사용자가 결과를 체감할 만큼 빠르게 가치를 주는가
- 수익화보다 재방문 이유가 먼저 설계되어 있는가
- 직접 입력만으로도 MVP가 굴러가도록 설계했는가
- 법적 문구와 예외 안내가 모든 핵심 화면에 반영되는가
