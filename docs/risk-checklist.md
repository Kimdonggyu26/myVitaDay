# 리스크 체크리스트

## 1. 데이터 범위 리스크

- MVP인데도 카탈로그 범위를 과도하게 넓히고 있지 않은가
- 인기 제품 적중률보다 전체 개수만 늘리고 있지 않은가

## 2. 데이터 출처 리스크

- 제품 정보 출처가 명확한가
- 가격 데이터 사용 방식이 문제 없는가
- 링크와 가격 갱신 기준이 문서화되어 있는가

## 3. 정규화 리스크

- 같은 성분이 다른 이름으로 중복 저장되지 않는가
- 함량 단위가 비교 가능하게 정리되어 있는가
- 같은 제품의 판매처별 가격이 정확히 묶이는가

## 4. 신뢰 리스크

- 상세 정보가 빈약해서 비교 가치가 떨어지지 않는가
- 가격이 오래되어 사용자를 실망시키지 않는가
- 비교 기준이 불명확하지 않은가

## 5. 의료 표현 리스크

- 제품 비교 문구가 효능을 단정하지 않는가
- 분석 결과가 의료 판단처럼 보이지 않는가
- 주의사항 문구가 과장되지 않는가

## 6. 운영 리스크

- 제품 데이터 업데이트 담당 방식이 정해져 있는가
- 판매처 링크가 깨졌을 때 점검 루틴이 있는가
- 잘못된 제품 정보 신고를 처리할 수 있는가

## 7. 보안 리스크

- 회원 정보는 안전하게 저장되는가
- 저장 목록과 내 영양제 데이터 접근 권한이 분리되는가
- 외부 링크 이동 과정에서 불필요한 정보가 노출되지 않는가

## 8. 출시 전 점검 질문

- 이 앱이 진짜 검색과 비교에서 시간을 줄여 주는가
- 사용자에게 저장할 이유가 분명한가
- 카탈로그 운영이 현재 팀 규모로 감당 가능한가
- 비교 기능이 다른 관리 기능보다 먼저 완성되었는가
