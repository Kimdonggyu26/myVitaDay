# 사용자 플로우

## 1. 핵심 퍼널

1. 앱 설치
2. 회원가입 또는 로그인
3. 건강 목표 선택
4. 영양제 1개 이상 등록
5. 분석 결과 확인
6. 루틴 저장
7. 알림 허용
8. 복용 체크
9. 재방문

## 2. 온보딩 플로우

1. 사용자가 앱을 처음 실행한다.
2. 서비스 소개 화면에서 핵심 가치를 본다.
3. 회원가입 또는 로그인을 진행한다.
4. 건강 목표를 선택한다.
5. 알림 권한 요청 전 사전 안내를 본다.
6. 홈 또는 영양제 추가 화면으로 이동한다.

## 3. 영양제 등록 플로우

1. 사용자가 영양제 추가 버튼을 누른다.
2. 검색 또는 직접 입력 방식 중 하나를 선택한다.
3. 제품명, 복용 횟수, 메모를 입력한다.
4. 저장 후 내 영양제 목록으로 이동한다.
5. 앱은 분석 재계산이 필요하다는 상태를 표시한다.

## 4. 분석 확인 플로우

1. 사용자가 분석 결과 화면에 진입한다.
2. 앱은 중복 성분을 우선 보여 준다.
3. 앱은 부족 가능성 성분군을 건강 목표 기준으로 보여 준다.
4. 앱은 일반 주의사항과 안내 문구를 함께 보여 준다.
5. 사용자는 루틴 생성 버튼으로 이동한다.

## 5. 루틴 생성 플로우

1. 사용자가 루틴 생성 버튼을 누른다.
2. 앱은 기본 슬롯별 자동 배치를 제안한다.
3. 사용자는 슬롯을 수정할 수 있다.
4. 사용자는 각 슬롯 알림 시간을 설정한다.
5. 저장 후 홈의 오늘 루틴으로 이동한다.

## 6. 복용 체크 플로우

1. 사용자가 알림을 받는다.
2. 홈 또는 알림 진입점에서 해당 슬롯을 연다.
3. 복용 완료를 누른다.
4. 앱은 오늘 복용률을 갱신한다.
5. 누락 시 다음 슬롯 전 또는 하루 마감 시 재안내를 보여 준다.

## 7. 구매 전환 플로우

1. 사용자가 분석 결과 또는 추천 영역에서 제품을 본다.
2. 제품별 성분, 가격, 특징을 비교한다.
3. 구매 링크를 누른다.
4. 외부 페이지로 이동한다.

## 8. 이탈 포인트와 대응

- 회원가입 직후 이탈
- 건강 목표 선택 단계를 짧게 유지하고, 등록 전 가치를 미리 보여 준다.
- 영양제 등록 중 이탈
- 직접 입력을 항상 열어 두고, 검색 실패 시 막히지 않게 한다.
- 분석 결과에서 불신
- 과장 표현을 피하고, 왜 이런 결과가 나왔는지 근거를 짧게 제공한다.
- 알림 거부
- 권한 요청 전에 알림을 켜면 무엇이 편해지는지 먼저 설명한다.
