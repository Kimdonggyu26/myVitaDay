# 사용자 플로우

## 1. 핵심 퍼널

1. 앱 설치
2. 회원가입 또는 로그인
3. 제품 검색
4. 제품 상세 확인
5. 제품 비교
6. 저장 또는 구매 링크 클릭
7. 재방문

## 2. 탐색 플로우

1. 사용자가 검색 화면에 진입한다.
2. 제품명이나 브랜드로 검색한다.
3. 결과 목록에서 제품을 선택한다.
4. 상세에서 핵심 성분, 함량, 가격을 확인한다.
5. 비교하기 버튼을 누른다.

## 3. 비교 플로우

1. 사용자가 제품 2개 또는 3개를 선택한다.
2. 앱은 성분, 함량, 가격, 특징을 같은 기준으로 정렬해 보여 준다.
3. 사용자는 더 적합한 제품을 고른다.
4. 관심 제품으로 저장하거나 구매 링크로 이동한다.

## 4. 저장 플로우

1. 사용자가 관심 제품 저장을 누른다.
2. 저장 목록에서 나중에 다시 비교할 수 있다.
3. 원하면 현재 복용 중 제품으로 전환 등록할 수 있다.

## 5. 내 영양제 플로우

1. 사용자가 제품을 내 영양제로 등록한다.
2. 메모와 복용 횟수를 추가한다.
3. 앱은 이후 분석 기능 진입점을 보여 준다.

## 6. 분석 확장 플로우

1. 사용자가 내 영양제 화면에서 분석을 실행한다.
2. 앱은 중복 성분과 기본 주의사항을 보여 준다.
3. 향후 부족 가능성과 루틴 기능으로 이어진다.

## 7. 구매 전환 플로우

1. 사용자가 상세 또는 비교 화면에서 판매처를 본다.
2. 가격과 판매처를 확인한다.
3. 구매 링크를 누른다.
4. 외부 페이지로 이동한다.

## 8. 재방문 플로우

1. 사용자가 저장 목록 또는 최근 본 제품을 보기 위해 다시 연다.
2. 가격 변동이나 비교 재확인을 한다.
3. 현재 복용 중인 제품을 정리한다.

## 9. 이탈 포인트와 대응

- 검색 결과가 빈약하면 이탈한다.
- 초기 카탈로그는 넓이보다 인기 제품 적중률을 높여야 한다.
- 상세 정보가 허술하면 신뢰를 잃는다.
- 가격 갱신 시점과 정보 출처 관리가 중요하다.
- 비교가 복잡하면 사용자가 피로해진다.
- 비교 UI는 한눈에 이해되게 단순해야 한다.
