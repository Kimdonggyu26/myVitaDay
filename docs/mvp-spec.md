# MVP 기획서

## 1. 문제 정의

영양제를 사려는 사용자는 아래 문제를 자주 겪습니다.

- 제품이 너무 많아 무엇을 봐야 할지 모르겠다.
- 광고성 설명은 많은데 성분과 함량 비교가 어렵다.
- 가격이 판매처마다 달라 어디서 사는 게 나은지 헷갈린다.
- 이미 먹는 영양제와 중복되는지 확인하기 어렵다.
- 사놓고도 꾸준히 챙겨 먹기 어렵다.

## 2. 타겟 사용자

- 영양제를 처음 고르는 입문 사용자
- 이미 여러 영양제를 복용 중이지만 비교가 어려운 사용자
- 가격과 성분을 함께 보고 합리적으로 구매하고 싶은 사용자
- 구매 후에도 내가 먹는 제품을 정리하고 싶은 사용자

## 3. MVP 핵심 가치

- 영양제를 가장 쉽게 찾게 해 준다.
- 제품 간 차이를 가장 쉽게 비교하게 해 준다.
- 가격과 판매처를 한눈에 보게 해 준다.
- 관심 제품과 내 제품을 저장해 나중에도 관리하게 해 준다.

## 4. 포지셔닝

`영양제를 사기 전에 가장 쉽게 비교해 주는 앱, 산 뒤에는 가장 편하게 정리해 주는 앱`

## 5. 필수 기능

### 제품 검색

- 제품명 검색
- 브랜드 검색
- 카테고리별 탐색

### 제품 상세

- 제품명
- 브랜드
- 주요 성분과 함량
- 1일 섭취량
- 특징 요약
- 주의 문구

### 제품 비교

- 최대 2개 또는 3개 제품 비교
- 성분, 함량, 가격, 특징 비교

### 가격 정보

- 판매처별 가격
- 링크 이동
- 업데이트 시점 표시

### 내 제품 저장

- 관심 제품 저장
- 현재 복용 중 제품으로 등록
- 메모 추가

## 6. 보강 기능

### 분석 기능

- 중복 성분 체크
- 부족 가능성 안내
- 기본 주의사항 안내

### 관리 기능

- 복용 루틴 생성
- 알림 시간 설정
- 복용 체크

## 7. 화면 구조

- 온보딩
- 홈
- 검색
- 제품 상세
- 제품 비교
- 내 영양제
- 분석 결과
- 알림 설정
- 마이페이지

## 8. 홈 화면 MVP 구성

- 최근 본 제품
- 저장한 제품
- 많이 비교하는 인기 제품
- 내 영양제 바로가기
- 추후 분석 기능 진입점

## 9. 사용자 스토리

- 사용자는 특정 영양제를 검색해서 상세 정보를 볼 수 있다.
- 사용자는 두 제품을 나란히 비교할 수 있다.
- 사용자는 가격과 판매처를 확인하고 구매 링크로 이동할 수 있다.
- 사용자는 관심 제품을 저장할 수 있다.
- 사용자는 현재 먹는 영양제를 내 목록에 넣을 수 있다.
- 사용자는 나중에 저장한 영양제를 기준으로 중복 분석을 받을 수 있다.

## 10. 성공 지표

- 검색 후 상세 진입률
- 상세 후 비교 진입률
- 비교 후 저장률
- 비교 후 구매 링크 클릭률
- 저장 후 재방문율
- 내 영양제 등록률

## 11. 운영상 주의점

- 제품 정보와 가격 갱신 주기를 명확히 표시해야 한다.
- 분석 결과는 참고 정보이며 의료 조언처럼 보이지 않아야 한다.
- 데이터 출처와 수집 범위를 내부적으로 관리해야 한다.

## 12. 4주 MVP 일정

### 1주차

- 프로젝트 구조 세팅
- 제품 카탈로그 스키마
- 검색 화면 초안

### 2주차

- 제품 상세 API
- 제품 비교 화면
- 가격 데이터 표시

### 3주차

- 관심 제품 저장
- 내 영양제 등록
- 기본 분석 설계

### 4주차

- 중복 성분 분석
- 홈 정리
- 구매 링크 흐름 점검
