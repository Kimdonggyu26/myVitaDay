# MVP 기획서

## 1. 문제 정의

사용자는 영양제를 여러 개 먹고 있어도 아래 문제를 자주 겪습니다.

- 지금 먹는 조합이 괜찮은지 알기 어렵다.
- 같은 성분을 중복 섭취할 수 있다.
- 필요한 성분을 놓칠 수 있다.
- 복용 시간이 헷갈리고 꾸준히 챙겨 먹기 어렵다.

## 2. 타겟 사용자

- 20대부터 50대까지 건강 관리에 관심 있는 사용자
- 피부, 피로, 수면, 다이어트, 운동 회복 등 명확한 목적이 있는 사용자
- 여러 영양제를 이미 먹고 있거나 처음 시작하려는 사용자

## 3. MVP 핵심 가치

- 현재 복용 상태를 한눈에 정리해 준다.
- 중복과 부족 가능성을 빠르게 알려 준다.
- 복용 루틴을 자동으로 만들어 준다.
- 알림과 체크로 복용 습관을 만든다.

## 4. 필수 기능

### 인증

- 이메일 회원가입
- 로그인
- 로그아웃

### 영양제 등록

- 제품 검색 등록
- 직접 입력 등록
- 1일 복용 횟수와 메모 저장

### 내 영양제 목록

- 등록 제품 목록 조회
- 제품 상세 확인
- 수정 및 삭제

### 성분 분석

- 중복 성분 표시
- 부족 가능성 표시
- 함께 복용 시 주의사항 표시

### 루틴 생성

- 아침 공복, 아침 식후, 점심 식후, 저녁 식후, 자기 전 슬롯 자동 분배
- 사용자 수동 수정 허용

### 알림 및 체크

- 시간 설정
- 알림 수신
- 복용 완료 체크

### 구매

- 추천 제품 리스트
- 제품 비교
- 외부 구매 링크 또는 제휴 구매 연결

## 5. 화면 구조

- 온보딩
- 로그인 / 회원가입
- 홈
- 내 영양제
- 영양제 추가
- AI 영양제 상담
- 분석 결과
- 루틴 편집
- 알림 설정
- 마이페이지

## 6. 홈 화면 MVP 구성

- 오늘 복용해야 할 루틴 카드
- 다음 알림 시간
- 복용 완료율
- 최근 분석 요약
- 영양제 추가 진입 버튼

## 7. 사용자 스토리

- 사용자는 현재 먹는 영양제를 입력해서 내 목록에 저장할 수 있다.
- 사용자는 저장된 목록을 바탕으로 어떤 성분이 겹치는지 확인할 수 있다.
- 사용자는 추천된 시간표대로 하루 복용 루틴을 받을 수 있다.
- 사용자는 알림을 받고 복용 체크를 남길 수 있다.
- 사용자는 부족 가능성이 있는 성분군을 보고 추가 구매를 검토할 수 있다.

## 8. 성공 지표

- 회원가입 후 첫 영양제 등록 전환율
- 첫날 루틴 생성 완료율
- 다음날 재방문율
- 알림 클릭률
- 복용 체크율

## 9. 운영상 주의점

- 의료 진단이 아니라 생활 관리 보조 서비스임을 명확히 고지해야 한다.
- 임산부, 만성질환자, 복용 약물이 있는 사용자는 전문가 상담 권장 문구가 필요하다.
- AI 상담 결과는 참고 정보로 안내해야 한다.

## 10. 4주 MVP 일정

### 1주차

- 앱 구조 세팅
- 인증 API
- 로그인 화면

### 2주차

- 영양제 등록과 목록
- 제품 검색 기본 기능

### 3주차

- 성분 분석 로직
- 분석 결과 화면

### 4주차

- 루틴 생성
- 알림 설정
- 복용 체크
