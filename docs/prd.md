# PRD

## 1. 제품 개요

### 제품명

Supplement Care MVP

### 제품 비전

사용자가 복잡한 영양제 정보를 쉽게 관리하고, 더 꾸준하게 복용하도록 돕는 개인 영양제 관리 앱을 만든다.

### 문제 정의

사용자는 현재 먹는 영양제가 자신에게 맞는지 확신하기 어렵고, 성분 중복이나 부족 가능성을 쉽게 파악하지 못한다. 또한 복용 시간이 헷갈리거나 습관이 잡히지 않아 지속적으로 챙겨 먹기 힘들다.

### 해결 방식

- 복용 중인 영양제를 등록한다.
- 성분 중복과 부족 가능성을 요약해 보여 준다.
- 하루 복용 루틴을 자동 생성한다.
- 알림과 복용 체크로 꾸준한 습관을 만든다.
- 필요 시 추천 제품 비교와 구매로 연결한다.

## 2. 목표와 비목표

### 목표

- 첫 방문 사용자가 10분 안에 영양제를 등록하고 분석 결과를 볼 수 있게 한다.
- 사용자가 하루 루틴을 저장하고 다음날 다시 방문할 이유를 만든다.
- 추천과 구매 기능을 붙이더라도 서비스 중심은 관리와 습관 형성에 둔다.

### 비목표

- 질병 진단 또는 치료 가이드 제공
- 복용 약물과의 의학적 상호작용을 전문적으로 판정
- 개인 검사 데이터 기반 정밀 영양 처방

## 3. 대상 사용자

### 1차 타겟

- 25세부터 45세까지의 건강 관심 사용자
- 이미 1개 이상 영양제를 복용 중인 사용자
- 피부, 피로, 수면, 다이어트, 운동 회복처럼 목적이 분명한 사용자

### 2차 타겟

- 영양제를 처음 시작하려는 입문 사용자
- 정리와 기록에 약하지만 알림 도움을 받고 싶은 사용자

## 4. 핵심 가치 제안

- 복잡한 영양제 조합을 한눈에 정리한다.
- 사용자의 건강 목표를 기준으로 현재 상태를 해석한다.
- 복용 루틴과 체크 기능으로 실천을 돕는다.

## 5. 주요 사용자 시나리오

### 시나리오 A

사용자는 회원가입 후 건강 목표를 선택하고 현재 먹는 영양제를 2개 이상 등록한다. 앱은 중복 성분과 부족 가능성을 요약하고, 자동 루틴을 제안한다.

### 시나리오 B

사용자는 아침과 저녁 알림을 받고 복용 여부를 체크한다. 앱은 오늘 복용률과 누락된 항목을 보여 준다.

### 시나리오 C

사용자는 분석 결과에서 부족 가능성이 보이는 성분을 확인하고 관련 제품을 비교한 뒤 구매 페이지로 이동한다.

## 6. MVP 범위

### 포함

- 이메일 회원가입과 로그인
- 온보딩 건강 목표 선택
- 영양제 검색 등록과 직접 입력 등록
- 내 영양제 목록 조회, 수정, 삭제
- 성분 기반 중복 체크
- 목표 기반 부족 가능성 표시
- 복용 루틴 자동 생성과 수동 수정
- 알림 시간 설정
- 복용 체크
- 추천 제품 목록과 구매 링크 연결

### 제외

- 소셜 로그인
- OCR 기반 제품 등록
- 실시간 약물 상호작용 판단
- 구독 결제
- 커뮤니티와 리뷰

## 7. 기능 요구사항

### 인증

- 사용자는 이메일과 비밀번호로 가입할 수 있어야 한다.
- 사용자는 로그인 후 세션이 유지되어야 한다.

### 온보딩

- 사용자는 건강 목표를 1개 이상 선택할 수 있어야 한다.
- 선택 가능한 예시는 피로, 수면, 피부, 다이어트, 운동 회복이다.

### 영양제 등록

- 사용자는 검색 결과에서 제품을 선택할 수 있어야 한다.
- 사용자는 제품이 없을 경우 직접 제품명을 입력할 수 있어야 한다.
- 사용자는 복용 횟수와 메모를 저장할 수 있어야 한다.

### 분석

- 앱은 중복 성분 목록을 표시해야 한다.
- 앱은 건강 목표 대비 부족 가능성이 있는 성분군을 표시해야 한다.
- 앱은 일반적인 주의사항을 표시해야 한다.

### 루틴

- 앱은 등록한 영양제를 시간 슬롯에 자동 배치해야 한다.
- 사용자는 슬롯을 수정할 수 있어야 한다.

### 알림과 체크

- 사용자는 슬롯별 알림 시간을 수정할 수 있어야 한다.
- 사용자는 복용 완료를 체크할 수 있어야 한다.
- 앱은 날짜별 복용 이력을 조회할 수 있어야 한다.

### 구매

- 사용자는 추천 제품 목록을 볼 수 있어야 한다.
- 사용자는 제품 가격 또는 특징을 비교할 수 있어야 한다.
- 사용자는 외부 구매 링크로 이동할 수 있어야 한다.

## 8. 비기능 요구사항

- 앱은 첫 핵심 화면이 3초 내에 열리는 것을 목표로 한다.
- 영양제 등록과 루틴 조회는 오프라인 재시도에 대비해 캐시 전략이 필요하다.
- 개인정보와 건강 목표 정보는 안전하게 저장되어야 한다.
- 분석 결과는 의료 진단으로 오인되지 않도록 표현 정책을 따라야 한다.

## 9. 성공 지표

- 가입 후 첫 영양제 등록 전환율
- 분석 결과 도달률
- 루틴 생성 완료율
- 다음날 재방문율
- 알림 클릭률
- 복용 체크율
- 추천 제품 클릭률

## 10. 운영 정책 초안

- 서비스 전반에 의료 진단이 아니라는 고지를 표시한다.
- 임산부, 만성질환자, 처방약 복용자는 전문가 상담 권장 문구를 표시한다.
- AI 상담 결과는 참고 정보이며 확정적 표현을 피한다.

## 11. 출시 전 필수 결정사항

- 건강 목표 분류 체계 확정
- 영양제 제품 데이터 소스 확정
- 추천 로직이 룰 기반인지 AI 보조형인지 확정
- 구매 링크 제휴 방식 확정
- 알림 채널과 정책 확정
