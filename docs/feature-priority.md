# 기능 우선순위

## P0 출시 필수

- 이메일 회원가입과 로그인
- 온보딩 건강 목표 선택
- 영양제 등록
- 내 영양제 목록 조회
- 성분 중복 분석
- 부족 가능성 분석
- 루틴 자동 생성
- 알림 시간 설정
- 복용 체크
- 기본 추천 제품 노출과 구매 링크 연결

## P1 출시 직후 보강

- 영양제 수정과 삭제 UX 개선
- 홈 대시보드 고도화
- 복용 통계
- 추천 근거 설명 강화
- AI 상담 화면 정식화
- 즐겨찾는 제품 저장

## P2 확장 기능

- 소셜 로그인
- OCR 제품 등록
- 가족 계정
- 구독 배송
- 커뮤니티
- 리뷰와 평점

## 지금 덜어내야 할 것

- 너무 이른 AI 자동 추천 고도화
- 정밀 의료 해석처럼 보이는 문구
- 지나치게 복잡한 성분 점수 시스템
- 초반부터 모든 쇼핑 기능을 직접 보유하려는 구조

## 개발 순서 제안

1. 인증과 온보딩
2. 영양제 등록과 목록
3. 분석 API와 결과 화면
4. 루틴 생성과 홈
5. 알림과 체크
6. 추천과 구매 연결

## 판단 기준

- 첫 주 안에 핵심 사용자 흐름이 이어져야 한다.
- 데이터가 부족해도 사용자가 막히지 않아야 한다.
- 법적 리스크가 큰 기능은 뒤로 미룬다.
- 습관 형성 기능이 구매 기능보다 먼저 안정화되어야 한다.
