# 기능 우선순위

## P0 출시 필수

- 이메일 회원가입과 로그인
- 제품 검색
- 제품 상세 정보
- 제품 비교
- 판매처별 가격 정보
- 관심 제품 저장
- 내 영양제 등록
- 구매 링크 이동

## P1 출시 직후 보강

- 중복 성분 분석
- 부족 가능성 안내
- 홈 개인화
- 최근 본 제품
- 즐겨찾기 정리 UX

## P2 유지율 강화

- 복용 루틴 생성
- 알림 시간 설정
- 복용 체크
- 가격 변동 알림

## P3 확장 기능

- AI 비교 요약
- 개인 맞춤 추천
- 리뷰와 평점
- OCR 등록
- 커뮤니티

## 지금 덜어내야 할 것

- 초반부터 시중 모든 영양제를 다 담겠다는 목표
- 모든 쇼핑몰의 실시간 가격 엔진
- 의료 조언처럼 보이는 고도화 분석
- 약사 상담 운영
- 정기구독과 직접 커머스 운영

## 개발 순서 제안

1. 인증과 제품 카탈로그 구조
2. 검색 API와 검색 화면
3. 상세 API와 상세 화면
4. 제품 비교 기능
5. 가격 정보와 구매 링크
6. 저장과 내 영양제 등록
7. P1 분석 기능
8. P2 루틴과 알림

## 판단 기준

- 사용자가 비교까지 도달하는 흐름을 먼저 완성한다.
- 저장과 재방문 이유는 비교 경험이 잡힌 뒤 붙인다.
- 데이터 운영이 감당 가능한 범위에서만 기능을 확장한다.
