# 데이터 전략

## 1. 왜 데이터 전략이 핵심인가

이 서비스의 메인은 검색과 비교이므로, 앱 화면보다 먼저 제품 데이터 구조와 운영 방식이 안정적이어야 합니다. 초반에 무리하게 `모든 영양제`를 모으려 하면 개발보다 데이터 운영이 먼저 무너질 가능성이 큽니다.

## 2. 현실적인 MVP 전략

### 장기 비전

- 가능한 많은 시중 영양제를 조회할 수 있는 카탈로그 구축

### MVP 현실화 방식

- 비교 수요가 높은 대표 제품군부터 시작
- 예시:
- 멀티비타민
- 비타민 C
- 마그네슘
- 오메가3
- 유산균
- 콜라겐

## 3. 첫 데이터 범위 제안

- 카테고리 5개에서 10개
- 카테고리별 대표 제품 30개에서 100개
- 총 300개에서 800개 수준으로 시작

이 정도면 검색과 비교 UX를 검증하기에 충분하고, 운영도 감당 가능합니다.

## 4. 제품 데이터 구성

- 제품명
- 브랜드
- 카테고리
- 1일 섭취량
- 주요 성분
- 성분별 함량
- 특징 요약
- 주의 문구
- 이미지

## 5. 가격 데이터 구성

- 판매처명
- 판매가
- 링크
- 배송 정보 선택
- 마지막 갱신 시각

## 6. 데이터 수집 방식 우선순위

### 1순위

- 수동 입력
- 관리자용 시드 데이터
- 제휴 또는 공개 가능한 데이터 소스

### 2순위

- 일부 판매처 연동
- 파트너 피드 수집

### 3순위

- 더 넓은 가격 비교 확장

## 7. 정규화 원칙

- 성분명은 내부 표준명을 둔다.
- 함량 단위는 가능한 공통 단위로 변환한다.
- 같은 제품의 판매처별 가격은 별도 테이블로 분리한다.
- 광고 문구와 사실 데이터는 분리한다.

## 8. 절대 초반에 약속하지 말아야 할 것

- 시중 모든 영양제를 완전 보유
- 모든 판매처 실시간 가격 반영
- 100퍼센트 정확한 성분 자동 비교

## 9. 성공 기준

- 사용자가 원하는 인기 제품을 꽤 높은 확률로 찾는다.
- 상세 페이지 정보가 믿을 만하다고 느낀다.
- 비교 결과만으로 구매 판단에 도움을 받는다.
- 데이터 갱신 정책이 명확하다.
