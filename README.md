# Supplement Care MVP

개인 맞춤 영양제 상담부터 조합 분석, 구매, 복용 관리까지 한 번에 제공하는 앱의 초기 설계 문서입니다.

## 제품 한 줄 정의

사용자의 복용 중인 영양제를 바탕으로 중복, 부족, 복용 루틴을 정리해 주고 구매와 복용 체크까지 연결하는 개인 맞춤 영양제 앱

## MVP 목표

- 사용자가 현재 먹는 영양제를 등록할 수 있다.
- 등록된 영양제를 기반으로 중복 성분과 부족 가능성을 확인할 수 있다.
- 하루 복용 루틴을 자동 생성하고 알림과 복용 체크를 남길 수 있다.
- 추천 영양제와 구매 흐름을 연결할 수 있다.

## 권장 기술 스택

- 앱: Expo React Native
- API: Spring Boot
- DB: PostgreSQL
- 인증: JWT + Refresh Token
- 푸시 알림: Firebase Cloud Messaging
- AI 상담: LLM API + 내부 프롬프트 템플릿

이 조합은 모바일 MVP를 빠르게 만들고, 알림과 추천 기능을 나중에 확장하기에도 적합합니다.

## 핵심 사용자 흐름

1. 회원가입 후 기본 건강 목적을 선택한다.
2. 현재 먹는 영양제를 검색 또는 직접 입력으로 등록한다.
3. 성분 분석 결과에서 중복, 부족 가능성, 주의사항을 확인한다.
4. 추천된 복용 시간대로 루틴을 저장한다.
5. 알림을 받고 복용 체크를 누른다.
6. 필요 시 추천 제품을 비교하고 구매한다.

## 우선 개발 순서

1. 인증과 기본 앱 구조
2. 영양제 등록과 목록
3. 성분 분석
4. 루틴 생성
5. 알림과 복용 체크
6. 추천과 구매 연결
